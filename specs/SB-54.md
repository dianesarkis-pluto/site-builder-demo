# SB-54 — Content report: reconcile history per page

## Contract

- `reconcileReport(dir = '.reconcile-history')` → array, one row per page in
  the registry (`listPages()` order): `{ pageId, when, driftCorrected }`.
- `when` = ISO timestamp of the page's most recent reconcile, taken from the
  snapshot filename (`<pageId>-<when>.json`). `driftCorrected` = that
  snapshot's `driftPct`, passed through at full precision (no rounding).
- Page with no snapshot → listed as never reconciled: `when: null,
driftCorrected: null`.
- Multiple snapshots for a page → the latest `when` wins.

## Edge cases

- Missing `.reconcile-history/` dir (ENOENT) → return `[]`, never throw.
- Non-`.json` entries in the dir are ignored.

## Out of scope

- Writing/mutating snapshots or pages — read-only. No publish-path changes.
- Rendering/formatting the report; callers format.

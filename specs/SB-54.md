# SB-54 — Content report: reconcile history per page

`lib/report.js` exports `buildReport(historyDir = '.reconcile-history')`.

## Contract

- Returns one entry per page in `PAGES` (order preserved):
  `{ pageId, when, driftCorrected }`.
- Reconciled page (a snapshot exists): `when` = snapshot timestamp parsed
  from the filename (`<pageId>-<when>.json`), latest if several;
  `driftCorrected` = the snapshot's `driftPct` (full precision, not rounded).
- Never-reconciled page (no snapshot): `when = null`, `driftCorrected = null`.

## Edge cases

- Missing `historyDir` → returns `[]`, no throw.
- Dir exists but empty → every page listed as never-reconciled.
- Multiple snapshots for a page → newest `when` wins.

## Out of scope

- No writes anywhere; read-only. No change to `lib/pages.js` / publish path.
- Drift threshold policy, formatting/printing the report.
